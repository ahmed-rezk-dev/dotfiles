## Sharing code between React web and React Native mobile applications can be a good idea, depending on your project's needs:

### What are we sharing.

-   Non-UI components

    -   Request hooks (React Query)
    -   Schemas for validation (Zod)
    -   Stores (Zustand)
    -   Typescript types
    -   Utils (String/Date formatting, Generic functions)
    -   Design tokens

-   Pros:

    -   Code Reusability

    -   Consistency

    -   Faster Development

    -   Cross-Platform Compatibility

    -   Developer Familiarity

-   Cons:

    -   Platform-Specific Needs

    -   Performance Differences

    -   Third-Party Libraries

    -   Ecosystem Differences
