- [ ] What are fragments?
      It's a common pattern or practice in React for a component to return multiple elements. Fragments let you group a list of children without adding extra nodes to the DOM. You need to use either `<Fragment>` or a shorter syntax having empty tag (<></>).
- [ ] Why using fragments but not devs?
      Fragments are a bit faster and use less memory by not creating an extra DOM node.
- [ ] What are hooks?

## Unit Testing

- [ ] Jest vs react-testing-library
      Jest and React Testing Library (RTL) are both tools used for testing React applications,
      but they serve different purposes. Jest is a JavaScript testing framework that provides a complete testing environment,
      including a test runner, assertion library, and mocking capabilities. React Testing Library, on the other hand,
      is a library specifically designed for testing React components by focusing on user behavior and interactions.

## UI design

- [ ] What is Atomic design?
      Atomic design is a methodology composed of five distinct stages working together
      to create interface design systems in a more deliberate and hierarchical manner.
      The five stages of atomic design are:
      1- Atoms.
      2- Molecules.
      3- Organisms.
      4- Templates.
      5- Pages.
